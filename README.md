# Jogo do Número Secreto

Jogo interativo em **HTML, CSS e JavaScript** no qual o jogador tenta descobrir um número sorteado de 1 a 10.

## Funcionalidades
- Sorteio aleatório de números
- Dicas indicando se o número secreto é maior ou menor
- Contagem de tentativas
- Reinício da partida
- Leitura de mensagens em voz alta com ResponsiveVoice
- Controle para evitar repetição dos números sorteados até completar o conjunto

## Tecnologias
HTML5, CSS3, JavaScript e ResponsiveVoice.

## Como jogar
1. Abra `index.html` em um navegador.
2. Digite um número entre 1 e 10.
3. Confira as dicas até acertar.
4. Use o botão de reiniciar para começar outra partida.

A narração depende do carregamento do serviço externo ResponsiveVoice.

## Estrutura
- `index.html`: interface e carregamento dos scripts
- `app.js`: lógica do jogo
- `style.css`: estilos
- `img/`: recursos gráficos

## Conceitos praticados
Manipulação do DOM, eventos, condicionais, funções, números aleatórios e arrays.

## Possíveis melhorias
Validar explicitamente valores fora do intervalo, eliminar variáveis globais implícitas e ampliar os testes.
